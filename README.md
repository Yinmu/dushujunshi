# 毒舌军师

**忍一时越想越气，退一步越想越亏。**

替你把话说回去，也替你把后果想明白。贴进对方的原话，三位军师各给一条能直接发出去的回复，外加一个吵架模拟器，陪你预演几轮再复盘。

## 三位军师长这样

**场景一：甩锅同事**

> 对方：「这个需求当时你也在会上啊，你没提出异议就等于同意了，现在出问题了你也有责任吧？」
>
> 🎭 **阴阳参谋**：懂了，开会没吭声就算签字画押。那按这个算法，拍板的人得负几倍责任？你先算，我等着。
>
> 🧠 **逻辑军师**：会上没反对，不等于这块归我负责。需求是你牵头的，验收也是你签的。先定位出问题的环节，该我改的我认。
>
> 🛡️ **稳场军师**：责任怎么分，会后对着纪要捋，不属于我的我不认。眼下先把问题修了，我这边能补的测试今天下班前给你。

**场景二：催婚亲戚**

> 对方：「你都三十了还不结婚，眼光别太高了，再挑下去好的都被别人挑走了，到时候你后悔都来不及。」
>
> 🎭 **阴阳参谋**：姨您说得对，好的都被挑走了，所以我更不能随便拿一个凑数，毕竟这事儿不支持七天无理由退货。
>
> 🧠 **逻辑军师**：结婚是为了过好日子，不是为了到某个岁数交作业。我现在过得挺好，遇到合适的自然会结，到时第一个通知您。
>
> 🛡️ **稳场军师**：谢谢姨惦记，这事我心里有数，咱就不在饭桌上聊啦。倒是听说表弟最近换工作了？新单位怎么样？

**场景三：周末加班的领导**

> 对方：「这个方案你周末加个班改一下，年轻人多锻炼锻炼。」
>
> 🎭 **阴阳参谋**：锻炼我是真想练，就是周末这个健身房不包加班费。我工作日加把劲，周一早上给您。
>
> 🧠 **逻辑军师**：可以改，先确认一下：方案是周一上午就要用吗？是的话我周五下班前把改动点列给您，周末只改必要部分。
>
> 🛡️ **稳场军师**：这周末我有安排来不了。方案周一中午前改完给您，特别急的部分您现在标出来，我今天先弄。

每张卡片还会附一句「发出去可能的后果」，好的坏的都说。发不发，你自己拿主意。

## 吵架模拟器

选一个练习目标（明确拒绝但不撕破脸 / 让对方闭嘴但不激化 / 当场接住话不愣住）和一个对手（甩锅同事 / 催婚亲戚 / 挑剔客户）。AI 扮演对方连续施压，最多 5 回合，随时可以结束。

结束后给你的是具体复盘，不是一个分数：

- ✨ 你哪句说得最好
- 🧭 你在哪一轮跑题、被带了节奏
- ✂️ 哪句话可以压缩成什么样

没有 key？首页点「看看示例」，用内置的两个示例场景走完整个流程（示例内容由人工写好，界面上有标注）。

## 为什么是 BYOK（自带 key）

- **零成本**：没有后端、没有服务器、没有订阅，用你自己的 key，按 token 付给模型厂商，一次几分钱。
- **隐私**：key 只存在你浏览器的 localStorage，请求从浏览器直接发到你填的接口，不经过任何第三方服务器。对话内容不落盘，刷新就没。
- **随便换模型**：支持任意 OpenAI 兼容接口，DeepSeek（默认）、Kimi、智谱、OpenAI 都行，改一下 Base URL 和模型名即可。

> 注意：接口需要允许浏览器直接调用（CORS）。如果遇到「网络请求失败」，多半是这个原因，换一家或者自己挂个代理。

## 本地运行

```bash
python3 -m http.server 8000   # 然后打开 http://localhost:8000
```

也可以直接双击 `index.html`。部署到 GitHub Pages / Cloudflare Pages / Vercel 都是纯静态，不用任何构建步骤。Cloudflare Pages 的话，新建项目、连上仓库、构建命令留空、输出目录填 `/` 就行。

## 军师人设和 prompt 在哪

| 军师 | 打法 |
|---|---|
| 🎭 阴阳参谋 | 用反讽指出不公平，好笑、好截图 |
| 🧠 逻辑军师 | 把争论拉回事实和责任 |
| 🛡️ 稳场军师 | 明确边界，同时留出合作空间 |

所有 prompt 都在 [`prompts.js`](app/prompts.js)：

- `REPLY_SYSTEM_PROMPT`：三位军师的人设和输出格式
- `RED_LINES`：红线（不拿年龄、地域、性别、外貌做攻击点；不编造对方的事实；讽刺对事不对人）
- `SIM_PERSONAS` / `SIM_TARGETS`：模拟器的对手人设和练习目标
- `REVIEW_SYSTEM_PROMPT`：复盘规则

内置示例在 [`examples.js`](app/examples.js)。
